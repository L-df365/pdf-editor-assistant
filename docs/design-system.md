# PDF 内嵌编辑助手 · 设计系统

> 方向代号：**样张台（Proof Desk）**
> 状态：已锁定（2026-10-20），按阶段落地中。

---

## 1. 方向

把一份 PDF 当成一份待校对的**样张**：台面是冷的、纸是白的、批注是墨青的、当前这一页被荧光笔划过。

**三个识别符**（只此三处，其余安静）：

| 识别符 | 形态 | 出现次数 |
|---|---|---|
| 页面轨 + 琥珀标记边 | 左侧窄栏＝等宽数字列 + 缩略图；当前页 3px 琥珀竖条 | 常驻，小面积 |
| 宋体只在空状态出现 | Noto Serif CJK SC 18pt「先打开一个 PDF」 | 全应用 1 次 |
| 等宽数字 | 页码、页数、比例、大小一律等宽，天然成列 | 贯穿 |

**明确不做**：奶油底 + 陶土色；近黑底 + 荧光绿；报纸式细栏密排；统一圆角卡片 + 同一层软阴影；全大写眉标；`A · B · C` 点号串；按钮文字后跟 `→`；渐变与玻璃拟态。

**已锁定决策**

| 项 | 决策 |
|---|---|
| 主色 | `accent` 墨青 + `marker` 琥珀（工具感、克制） |
| 菜单栏 | 保留系统原生控件，只换配色 |
| 文件选择 | 自建「快速入口面板」，系统对话框降级为「浏览全部文件…」兜底 |
| 拖放 | **放弃**「从文件管理器拖文件进窗口」；**保留**页面之间的拖拽排序（并增强为插入位置指示线） |
| 外部文件关联 | 通过 `.desktop` 的 `MimeType=application/pdf`，双击即用本应用打开 |
| 深色模式 | 不做（只支持浅色） |

## 2. 令牌

实现于 `gui/theme.py`，**所有组件从该模块取色取字，禁止再写死色值**。

### 2.1 颜色

| Token | Hex | 用途 |
|---|---|---|
| `BG` | `#EDF0EF` | 应用底色（冷中性台面） |
| `SURFACE` | `#F7F9F8` | 面板 / 标题条 / 工具条 |
| `PAPER` | `#FFFFFF` | 纸张：页面卡、输入框、弹层 |
| `STAGE` | `#D8DEDD` | 预览台面（比 surface 深一档，让白纸浮起来） |
| `LINE` | `#D3D9D7` | 1px 分隔线、卡片描边 |
| `LINE_SOFT` | `#E3E8E6` | 弱分隔、滚动条轨道 |
| `INK` | `#1B2321` | 主文字（近黑带绿调，非 `#0B0B0B`） |
| `INK_2` | `#586460` | 次要文字（≈5.5:1） |
| `INK_3` | `#8B9693` | 三级 / 禁用（≈2.7:1，禁用于正文） |
| `ACCENT` | `#0F7368` | 墨青：主操作、焦点环、链接（≈5.3:1） |
| `ACCENT_DEEP` | `#0A544C` | hover / press |
| `ACCENT_TINT` | `#E2EFEC` | 选中底、标签底 |
| `MARKER` | `#E9A62A` | 荧光琥珀：**仅**当前页标记、进行中 |
| `MARKER_INK` | `#8A5A00` | 琥珀底上的文字（≈5:1） |
| `DANGER` | `#B4462F` | 删除、破坏性动作（≈6:1） |
| `OK` | `#2F7D5B` | 已保存、状态点「可用」 |

规则：`ACCENT` 只给交互，`MARKER` 只给"当前 / 进行中"，两者面积比 ≤ 1:10。

### 2.2 字体

| 角色 | 字族 | 字号 | 用途 |
|---|---|---|---|
| Display | Noto Serif CJK SC | 18pt | 空状态主标题（**全应用仅此一处**） |
| H1 | Noto Sans CJK SC Bold | 13pt | 面板 / 弹层标题、文档名 |
| H2 | Noto Sans CJK SC Bold | 11pt | 区块标题、按钮 |
| Body | Noto Sans CJK SC | 10pt | 正文、菜单项、输入 |
| Meta | Noto Sans CJK SC | 9pt | 说明文字、次要标签 |
| Num | Noto Sans Mono CJK SC | 9pt | 页码、页数、比例、尺寸 |

字体栈（缺失自动降级）：`Noto Sans CJK SC → Source Han Sans SC → Microsoft YaHei → WenQuanYi Micro Hei → DejaVu Sans`；衬线 `Noto Serif CJK SC → Source Han Serif SC → STSong → SimSun`；等宽 `Noto Sans Mono CJK SC → Noto Sans Mono → DejaVu Sans Mono`。

### 2.3 间距 / 圆角 / 光标

- 间距基数 4：`4 / 8 / 12 / 16 / 24 / 32`。窗口外边距 16，面板间 12，卡内 8，按钮内 12×5，图标↔文字 6，命中区 ≥ 28px。
- 圆角 `0 / 2 / 4 / 6`，默认 3；页面卡 2，按钮/输入 3，弹层 6。ttk 无圆角，仅页面卡与标记条用 Canvas 自绘。
- 光标：可点 `hand2`、可拖 `fleur`、等待 `watch`、输入 `xterm`。

## 3. 组件规范

### 3.1 卡片

**全应用只允许一种卡片：页面卡。** 其余区域一律用 1px 分隔线分区。

页面卡：底 `PAPER`、描边 1px `LINE`、r2、内边距 6、**无阴影**；左侧 3px 标记条（未选 `PAPER`，选中 `MARKER`）；选中时描边转 `ACCENT`、底转 `ACCENT_TINT`、页码转 `ACCENT` 加粗（颜色 + 粗细双编码）。

### 3.2 按钮

| 档 | 形态 | 高度 |
|---|---|---|
| Primary | 底 `ACCENT`，白字加粗 | 32（空状态 40） |
| Secondary | 底 `SURFACE`，1px `LINE`，`INK` 文字 | 32 |
| Ghost | 无底，`INK_2` 文字，hover 底 `ACCENT_TINT` | 28 |
| Danger Ghost | Ghost + `DANGER` 文字 | 28 |

焦点：2px `ACCENT` 外环。禁用：`INK_3` 文字、无描边。文案为动词短语、说清结果（`打开 PDF` / `插入文件` / `保存` / `插入 3 页`），**不加 `→`**。

### 3.3 菜单

> **结构决定**：早期版本有「文字菜单栏 + 文档标题栏」两条顶栏，命令重复、层级打架。
> 现在**只有一条顶栏**（文档身份 + 常用动作 + `⋯` 溢出），所有低频命令集中在 `⋯` 浮层里。

三个菜单面（顶栏 `⋯`、页面轨右键、预览区右键）共用一套**菜单语法**，并且是**自绘浮层**
（`gui/menu.py` 的 `MenuPopover`）：纸白底、1px 细线、柔和投影、右对齐等宽快捷键列、
危险项红色、悬停墨青底。`tk.Menu` 只能改颜色，做不出这套语言，所以弃用。

1. 分组 ≤ 3 组、每组 ≤ 4 项，用分隔线分组。
2. 文案动词开头、带上下文时写明对象（`在第 3 页后插入文件`）。
3. 危险动作永远最后一条、独立成组、`DANGER` 文字，触发确认面板而非子菜单。
4. 快捷键右对齐列，`INK_3`。
5. **禁用而非隐藏**（未打开文档时"旋转/删除"置灰保留）。
6. 同一动作只在一处出现，快捷键唯一。

`tk.Menu` 只能改颜色/字体/边框（无圆角、无阴影、不能调行高），外观靠 `gui/menu.py` 的 `style_menu()` 统一。右键菜单**单实例**，打开时用 `postcommand` 刷新页码文案。

**顶栏 `⋯` 浮层**（原来的文字菜单栏已并入这里）

```
适应页面 Ctrl+0 / 实际大小 100% Ctrl+1 / 放大 200% Ctrl+2
──
页面信息… Ctrl+Shift+I / 重新载入文件
──
转换后端… Ctrl+,
──
快捷键 Ctrl+/ / 关于本应用
```

**页面轨右键**：`在第 N 页后插入文件…` / ─ / `逆时针旋转 90°` / `顺时针旋转 90°` / ─ / `删除第 N 页`（危险）。
**预览区右键**：`适应宽度` / `实际大小 100%` / `放大 200%` / ─ / `导出当前页为图片…` / `在第 N 页后插入文件…`。
**`⋯` 溢出**：`页面信息…` / ─ / `转换后端设置…` / `重新载入文件` / ─ / `关于本应用`。

### 3.3.1 卡片与浮层

- 浮层菜单、模态面板都是**自绘的圆角纸面卡片**：四角用 `pieslice` 拼（`smooth`
  多边形画出来还是方角），描边单独画，下面铺三层偏移投影。
- 模态面板**无系统边框**（`overrideredirect`），自带头部标题与 `×`，
  不再有"系统标题栏 + 面板标题"重复两遍的情况。
- 浮层菜单任何时候都能消失：点菜单外、点别处右键、按 `Esc`。

### 3.4 反馈

| 场景 | 组件 |
|---|---|
| 可恢复提示 | `Toast`：右下角，3.5s 自动消失，`PAPER` 底 + 1px `LINE` + 左侧 3px `OK`/`DANGER` 色条 |
| 破坏性确认 | `ConfirmPanel`：标题 + 一句话说清后果（含对象与数量）+ 取消 / 确认（危险色） |
| 错误 | `ErrorPanel`：标题 + **人话正文** + 「诊断详情」折叠 + 「复制详情」；不出现 `HRESULT=…` |
| 进度 | 状态栏左侧 2px 细进度条 + 状态文案；转换期间预览区保持可交互 |

文案示例：
- ✗ `WPS 转换失败: Documents.Open 失败，HRESULT=0xfff40005`
- ✓ 标题「转换失败」／正文「这个文档正被 WPS 打开着，关掉它再试一次。」／折叠内「诊断详情」

### 3.5 滚动条

无箭头细条：轨道 `BG`、滑块 `LINE_SOFT`、hover `INK_3`、按下 `INK_2`，宽 10px。

## 4. 页面规范

### 4.1 主界面

```
┌ report.pdf ●      [打开][插入][撤销][重做]            [保存]  [⋯] │ 顶栏 48px
├──────────┬──────────────────────────────────────────────────
│ 01 ▨     │  ┌ ↺逆时针 ↻顺时针 ＋在此后插入 ⌫删除此页 ┐          │ ← 浮在台面上
│ 02 ▨     │  │        ┌────────────────────────┐    │          │
│ ▌03 ▨    │  │        │      页面预览（纸白）     │    │          │
│ 04 ▨     │  │        └────────────────────────┘    │          │
├──────────┴──────────────────────────────────────────────────
│ 适应│50%│100%│200%                              03 / 12      │ 预览底栏 26px
├──────────────────────────────────────────────────────────────
│ 就绪                                       共 12 页  WPS ●   │ 状态条 26px
└──────────────────────────────────────────────────────────────
```

- **只有一条顶栏**：左边是字标（宋体「PDF 内嵌编辑助手」），右边是常用动作
  （打开 / 插入 / 保存 / `⋯`）。**文件名不再重复**——窗口标题栏已经承担了它，
  长文件名不会把按钮挤掉；未保存状态用保存按钮旁的琥珀点表示。
- **撤销 / 重做在浮条上**，用 `←` / `→` 两个返回箭头（带 hover 提示），不在顶栏。
- **页面级动作浮在台面上**（白底小工具条），不是第二条窗口栏。
- **撤销 / 重做**：基于快照，保留 5 步；`Ctrl+Z` / `Ctrl+Shift+Z`；不可用时按钮置灰；
  状态条提示「已撤销（还能撤销 2 步）」。

- 标题条与状态条两端对齐内容列；状态条左＝一句人话，右＝事实型信息，**不用竖线串联**。
- 状态条只放文件名；完整路径进 tooltip 与「页面信息」面板。
- 页面轨：等宽索引列 + 缩略图；面板 ≥ 280px 自动两列；缩略图宽度**跟随面板宽度自适应**（消除裁切）。
- 预览台 `STAGE` 底 + 页面投影；页码计数 `03 / 12`（等宽，右下）。

### 4.2 空状态（"首页"）

```
        先打开一个 PDF                    ← Noto Serif CJK SC 18pt
        也可以直接把 Word、Excel、图片插进来，
        转成页面放到任意位置。              ← 10pt INK_2 行距 1.5

        [ 打开 PDF ]   [ 插入文件 ]

        Ctrl+O 打开　·　在文件管理器里双击文件即可用本应用打开
```

不放插画；用一条 3px `MARKER` 竖条做视觉锚点，与当前页标记呼应。

### 4.3 插入面板

```
  插入文件
  要插入
  讲义.pdf、笔记.docx 等 3 个文件
  插到哪里
  (•) 当前页之后（第 4 页）
  ( ) 文末（第 15 页）
  ( ) 指定位置：第 [ 5 ] 页之前
  ─────────────────────────────────────────
              [ 插入 3 个文件 ]  [ 取消 ]
```

- 位置默认「当前页之后」——这是最常见的意图；不用数字输入框让人猜页码。
- 按钮写明数量：「插入 3 个文件」。页数在转换前不可知，因此不预告页数。
- 完成后 toast「已插入 3 页，共 18 页」；个别文件失败时弹错误面板，列出失败项，
  其余文件照常保留（不回滚）。

### 4.4 转换后端设置窗口

```
  转换后端
  后端不随应用安装，只调用本机已安装的程序。

  ○ 自动选择        WPS 静默转换可用      ●
  ● WPS 静默转换    WPS 静默转换可用      ●
  ○ LibreOffice     未找到 soffice          ○  [ 打开软件商店 ]
```

每行：名称 + 状态点 + 原因 + 动作；复用 `core/backends/installer.py` 的 `open_app_store()` / `install_backend()`。

### 4.5 文件选择面板（快速入口）

```
┌ 打开 PDF ─────────────────────────────────────────────── ✕ ┐
│  ┌ 常用位置 ─────────┐  ┌ 文件 ─────────────────────────┐   │
│  │ ▸ 当前文档所在文件夹│  │ ☑ 名称       修改时间     大小   │   │
│  │   report.pdf    2h │  │ ─────────────────────────────│   │
│  │ ▸ 最近使用         │  │ ☑ 讲义.pdf   10-19 14:32  1.2M │   │
│  │ ▸ 桌面 / 下载      │  │ ☐ 笔记.pdf   10-18 09:10  240K │   │
│  └────────────────────┘  └────────────────────────────────┘   │
│  ┌ 预览 ─────────────┐                                        │
│  │  [第 1 页缩略图]   │                                        │
│  │  1.2 MB · A4 · 3 页│                                        │
│  └────────────────────┘                                        │
│  文件名或完整路径 [________________]  [ 打开 ] [ 取消 ]         │
│  浏览全部文件…                                                │
└───────────────────────────────────────────────────────────────┘
```

- **「当前文档所在文件夹」置顶且为插入流程的默认目录**——要合成的东西通常就在同一个文件夹里。
- 同目录文件带类型徽标（PDF / Word / Excel / 演示 / 图片）；当前 PDF 标记「当前文档」且不可再选。
- 底部路径框可直接粘贴完整路径或 `~/…`，回车打开——最被低估的入口。
- 「浏览全部文件…」调系统对话框兜底（网络位置、特殊权限、隐藏文件），并把当前目录与类型过滤带过去。
- 键盘：`↑↓` 选择、`Enter` 打开、`Esc` 取消、`Ctrl+L` 聚焦路径框、`Alt+↑` 上级目录。

### 4.6 多选（插入文件）

- 文件列表带**复选框列**（Ctrl/Shift 为快捷方式）；单选场景隐藏复选框。
- 底部显示「已选 3 个文件 · 预计 7 页」。
- 插入顺序 = **文件名字典序**（可预期，界面里写明）。
- 单文件失败不回滚其它文件，报「3 个文件中 1 个失败：xx.docx（正被 WPS 打开）」。
- 数据层已就绪：`PDFDocument.insert_files(paths, position)` 返回逐文件结果（`path/ok/error/pages`）。

## 6. 术语表（`gui/strings.py` 为唯一来源）

| 统一用词 | 禁止 |
|---|---|
| 打开 / 另存为 / 保存 | — |
| **插入** | 添加、导入、放入 |
| **页面**（正式）/ 第 N 页（页码） | 页、纸张 |
| **转换后端** | 转换引擎、后端、转换器 |
| **顺时针 / 逆时针旋转 90°** | 左旋 / 右旋 |

### 已实现的细节（与本文件的差异）

- 插入位置面板用三个单选（当前页之后 / 文末 / 指定第 N 页），主按钮写「插入 N 个文件」；
  页数在转换前不可知，因此不预告页数。
- 快速入口面板用 `ttk.Treeview` 承载文件列表：选择列显示 `✓`（墨青），支持「全选」，
  插入顺序按文件名字典序。当前打开的 PDF 在列表里置灰并标为「当前文档」。
- 后台任务（转换、安装）只往队列里投递结果，由主线程统一消费，避免跨线程操作 Tk。
- 页面轨拖拽排序时在插入点画一条 2px 墨青指示线。
